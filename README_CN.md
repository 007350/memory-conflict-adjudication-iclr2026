# 中文场景下记忆冲突的可信度裁决：贝叶斯框架与中文语用信号的实证研究

> ICLR 2026 投稿版（匿名）。仓库内含 LaTeX 源码、5 张论文图与已编译的 PDF。
> English version: [README.md](README.md)

## 一句话概括

长期运行的 AI agent 记忆里，同一事实常出现互相矛盾的说法，主流系统只会用「时间最新者胜」
（last-write-wins）或临时让 LLM 临场判断。英文里已有「可信度条件贝叶斯裁决」的探索，
但它能不能搬到中文——中文的认识情态、语域、指代消解都和英文不同——此前没人验过。

本文是**首个中文场景下的可信度记忆冲突裁决实证研究**。我们构建 240 条中文冲突评测集
（`conflict-cn v1.0`，对齐 LongMemEval 题型分类），其中 45% 是**「旧说法更可信」的对抗样本**，
能把可信度裁决与新近性启发式区分开。

## 主要结果（n = 240）

| 方法 | 总体准确率 [95% CI] | 对抗子集 (n=108) | 非对抗 (n=132) | 误覆盖率 | LLM 调用 |
|---|---|---|---|---|---|
| B1 last-write-wins | 0.5500 [0.4868, 0.6117] | 0.0000 | 1.0000 | 1.0000 | 0 |
| B2 规则检测+时间裁决 | 0.5500 [0.4868, 0.6117] | 0.0000 | 1.0000 | 1.0000 | 0 |
| B3 LLM zero-shot（DeepSeek 真实调用） | 0.9625 [0.9303, 0.9801] | 0.9167 | 1.0000 | 0.0833 | 240 |
| B4 贝叶斯复现（Nous，去掉英文专属组件） | 0.9833 [0.9579, 0.9935] | 1.0000 | 0.9697 | 0.0000 | 0 |
| **Ours（全量）** | **1.0000 [0.9842, 1.0000]** | 1.0000 | 1.0000 | 0.0000 | 0 |
| Ours + LLM 检测（DeepSeek 真实调用） | 1.0000 [0.9842, 1.0000] | 1.0000 | 1.0000 | 0.0000 | 240 |

几点解读：

- **B1/B2 对抗子集 0/108 全错**——「时间最新者胜」在「旧说法更可信」场景下系统性失效，这正是本研究的动机。
- **B4 在中文数据上 0.9833**：英文验证过的贝叶斯裁决范式在中文下基本成立（RQ1 的首要答案）。
- **Ours 240/240，但与 B4 的 4 条差距 McNemar 精确检验 p=0.125，不显著**——本文不夸大「1.0000 vs 0.9833」。
- **B3 纯 LLM zero-shot 0.9625，9 条错误全在对抗子集**，失效模式是「自信-新近性偏置」：
  措辞自信的新说法压过了模糊限制语信号。它的错误与 B4 的 4 条错误零重叠，两类方法踩的坑不同。
- **Ours+LLM 检测与规则检测版逐条完全一致**：240 次调用、约 4.8 万真实 token 没有换来任何增益。

### 消融：中文信号值多少

中文语用信号整体贡献 **+30.00pp**（McNemar，p = 4.2×10⁻²²）：

- **模糊限制语强度（三级）**主导：**+13.33pp**
- **语域**呈冗余-互补模式
- **佐证计数**在当前数据上不可识别

## 方法

把中文语用信号——**三级模糊限制语强度、语域、指代风险**——形式化为
**三元组可信度模型**（来源类型先验、语用特征、佐证计数）的可靠性特征，
配合**贝叶斯后验裁决**、**来源上限**与**影子证据审计**。
检测与裁决解耦，因此漏检是降级而非灾难。
